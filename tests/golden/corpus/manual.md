# Manual de Operação

Este manual descreve a operação diária da plataforma Zeta.

## Manutenção

A janela de manutenção programada ocorre todo domingo às 03:40, quando o serviço de relatórios fica indisponível por até vinte minutos.

A equipe de plantão deve confirmar o backup da base antes de iniciar a janela.

## Erros conhecidos

O código de erro E-4471 indica falha no sistema de resfriamento do servidor de armazenamento.

O código E-9020 indica que o certificado do painel expirou e precisa ser renovado.

## Compras

O fornecedor Aurora entrega as baterias dos nobreaks e tem garantia de carência zero para trocas em até trinta dias.
